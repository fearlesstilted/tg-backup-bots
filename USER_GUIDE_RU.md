# Инструкция по пользованию ботами

## Какие есть боты

Есть два бота:

- **Reviews bot** — для отзывов.
- **Private bot** — для приватных чатов.

В каждом боте есть два направления:

- RU
- Foreign

## Что делает пользователь

1. Пользователь нажимает ссылку на нужного бота.
2. Бот показывает приветствие.
3. Пользователь нажимает кнопку:
   - `✅ Подтвердить` для RU;
   - `✅ Confirm` для Foreign.
4. Бот отправляет актуальную ссылку на нужный чат или канал.
5. Пользователь сохраняется в базе и становится доступен для emergency-рассылки.

## Что делает админ

Админ открывает нужного бота и пишет:

```text
/menu
```

После этого появятся кнопки:

- `📊 Статистика`
- `📜 Последние`
- `📣 Рассылка RU`
- `📣 Рассылка Foreign`
- `ℹ️ Помощь`

## Как посмотреть статистику

Нажать:

```text
📊 Статистика
```

Или командой:

```text
/stats
```

Бот покажет пользователей по сегментам:

- total — всего зарегистрировано;
- optin — подтвердили подписку;
- active — активны для рассылки.

## Как отправить рассылку

1. Открыть нужного бота: Reviews или Private.
2. Нажать `📣 Рассылка RU` или `📣 Рассылка Foreign`.
3. Отправить текст рассылки.
4. Бот покажет preview и количество получателей.
5. Нажать:
   - `Dry-run` — проверить без отправки;
   - `Отправить` — реально отправить;
   - `Отмена` — отменить.

## Как проверить последнюю рассылку

Кнопка:

```text
📜 Последние
```

Или команда:

```text
/last
```

## Как остановить рассылку

Если рассылка уже запущена:

```text
/stop_broadcast ID
```

ID будет виден после запуска рассылки.

## Как отменить ввод рассылки

Если нажали рассылку или написали `/broadcast`, но передумали:

```text
/cancel
```

Бот очистит текущий режим и вернёт меню.

## Как проверить статус рассылки

```text
/broadcast_status ID
```

## Как отправить тест самому себе

```text
/test ru_reviews
```

или:

```text
/test foreign_reviews
```

В Private bot:

```text
/test ru_private
/test foreign_private
```

После команды отправьте текст, и бот пришлёт его только вам.

## Где хранится база пользователей

База хранится на VPS:

```text
/opt/tg-backup-bots/bots.db
```

Там лежат Telegram ID, username, язык, сегмент, статус подписки и история рассылок.

## Главное правило

Перед реальной массовой рассылкой сначала нажимать `Dry-run`.
